# featheranalytics.github.io

Personal site for [Feather](https://www.featheranalytics.dev) — data projects, talks, and writing by David Hardage.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com). Deployed to GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
